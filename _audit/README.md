# Audit artifacts

`sheets/` — twelve contact sheets covering all 557 screens of the Higgsfield capture set,
48 screens per sheet, each thumbnail labelled with its source number. Generated from
`~/Desktop/Higgsfield web Sep 2026/` so the set could be reviewed as a whole and specific
screens located quickly.

These are working files, not part of the design system. Delete the folder whenever you like;
nothing in `tokens.css`, `components.css` or `index.html` depends on it. The screen numbers
cited in `EVIDENCE.md` §12 refer to the original filenames, which these sheets index.
