## Design Context

### Users
Marketing teams, growth marketers, and creative strategists use Spyy to research a brand's active video advertising. Their core job is to move from a brand or app name to a trustworthy, source-aware set of creatives, while understanding identity confidence, source coverage, freshness, and scan cost.

### Brand Personality
Sharp, technical, and decisive. The interface should feel like a serious intelligence instrument: dense enough for research, calm enough for long sessions, and explicit whenever evidence is partial or uncertain.

### Aesthetic Direction
An editorial intelligence workspace built from the existing Spyy design system. Asta Sans carries the product UI; Archivo Black is reserved for display moments. Lime is used for actions, green for successful state, neutral surfaces for evidence, and the existing light/dark semantic token modes remain the only theme source. The supplied Figma flow establishes the compact search bar, dense media grid, and evidence-first detail direction; the current live dashboard supplies the content and information architecture.

### Design Principles
- Make evidence scannable: brand, source, age, and status should be visible before descriptive copy.
- Keep the primary action unambiguous: lime means the user can act; green reports that something succeeded.
- Preserve provenance: distinguish live-product facts, design-system rules, and inferred composition.
- Prefer progressive density: a simple search first, then filters and richer intelligence as the user moves deeper.
- Treat responsive layouts as a change in working mode, not a shrunken desktop canvas.
